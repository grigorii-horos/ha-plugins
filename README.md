# ha-plugins

Кастомные карточки для Home Assistant: несколько сущностей, собранных в одну плитку
по смыслу.

Одна физическая вещь в HA превращается в десяток плиток — Zigbee-розетка даёт 13
сущностей, робот-пылесос 78, компьютер через lnxlink все 100. Эти карточки собирают из
них то, ради чего на устройство смотрят.

## Устройство

Карточки **не повторяют вёрстку штатной плитки, а собираются из её компонентов** —
`ha-tile-container`, `ha-tile-icon`, `ha-tile-info`, `hui-card-features`. Оттуда же
берутся ripple, жесты, кольцо фокуса и штатные features. Своего в карточке только то,
чего у плитки нет: правая колонка с крупными значениями, отдельная цель тапа у каждой
величины и строки уровней.

Подробности, включая обоснование решений и список того, чего против штатной плитки
нет, — в [спецификации](docs/superpowers/specs/2026-09-04-ha-tile-cards-design.md).

| Тип | Что показывает |

| `horos-climate-tile` | температура, влажность, освещённость, PM2.5 комнаты |

| `horos-buttons-tile` | сетка кнопок, вызывающих скрипты |
| `horos-printer-tile` | уровни чернил и состояние принтера |
| `horos-vacuum-tile` | пылесос: заряд и ресурс расходников |
| `horos-batteries-tile` | только садящиеся батарейки |
| `horos-safety-tile` | протечка, дым, газ — и датчики без связи |
| `horos-server-tile` | диск, скорости, состояние сервисов |
| `horos-person-tile` | дома ли человек и заряд его устройств |
| `horos-computer-tile` | самая горячая точка, загрузка, диски |
| `horos-air-tile` | очиститель, рекуператор, увлажнитель |

## Установка

Репозиторий готов к установке через HACS как кастомный: HACS → Frontend → ⋮ → Custom
repositories → адрес этого репозитория, категория Lovelace. Собранный
`dist/ha-plugins-cards.js` лежит в репозитории, поэтому доступ к файловой системе
Home Assistant не нужен.

## Обновление на своём Home Assistant

```sh
script/publish.py
```

Собирает бандл, кладёт его в `www/` на хосте HA и обновляет ресурс дашборда, добавляя к
адресу хеш содержимого. Версия в адресе обязательна: без неё HA продолжает отдавать
закешированный старый файл, и обновление проходит незаметно для браузера.

Хост и путь берутся из `HA_SSH_HOST` и `HA_WWW`, адрес и токен — из
`HOME_ASSISTANT_URL` и `HOME_ASSISTANT_KEY`.

## Разработка

```sh
cd cards
npm install
npm run dev     # http://<этот-хост>:5188
npm test
npm run build   # ../dist/ha-plugins-cards.js — его и ставит HACS
```

Dev-режим нужен, только пока карточки правятся: дашборд тогда грузит их прямо с машины
разработчика: в ресурсы дашборда
добавляется модуль `http://<хост>:5188/src/main.ts`. Дашборд при этом открывается по
**http**, иначе браузер зарубит http-модуль как mixed content. Обновление — F5:
переопределить зарегистрированный custom element в живой странице нельзя.

Папка `frontend/` — клон исходников home-assistant/frontend. Она не часть проекта и не
версионируется, но нужна как справочник по вёрстке и токенам.
